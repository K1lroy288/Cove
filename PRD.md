## 1. Product Vision

**Cove** — приватный мессенджер с голосовыми комнатами для небольших групп друзей.

**Одна фраза:** Discord-уровень голоса + Telegram-простота + приватность по умолчанию.

### Чем Cove отличается от конкурентов

| Конкурент | Что не так |
|---|---|
| Discord | Перегружен серверами, каналами, ботами; публичен по умолчанию |
| Telegram | Голос — вторичная фича, нет постоянных комнат |
| WhatsApp | Голосовые звонки, не комнаты; нет PC-первого опыта |
| Clubhouse | Только голос, нет личных сообщений |

**Уникальные фичи Cove:**
1. Постоянные голосовые комнаты (зашёл/вышел как в Discord, но только для друзей)
2. Только друзья — нет публичных серверов и случайных людей
3. Голос как равноправная фича, а не дополнение к тексту
4. Минималистичный UI — меньше элементов, больше функций

## 2. Target Users

**Основная аудитория:** группы друзей (3–15 человек), которые хотят:
- Общаться в тексте и голосе без настройки серверов
- Иметь "общую комнату" где можно просто висеть голосом
- Не видеть рекламу, ботов и незнакомцев

**Вторичная аудитория:** небольшие команды (до 20 человек) для неформального общения.

## 4. Acceptance Criteria

### US-05 — Принять/отклонить заявку

- [ ] При нажатии ✓ заявка исчезает из списка, отправитель появляется в друзьях у обоих
- [ ] При нажатии ✗ заявка исчезает, дружба не создаётся
- [ ] Действия работают мгновенно (optimistic update)
- [ ] При ошибке сети — откат состояния + toast с описанием ошибки
- [ ] После принятия заявки появляется возможность начать чат

### US-11 — Отправка/получение сообщений в реал-тайме

- [ ] Сообщение отображается у отправителя сразу (optimistic UI)
- [ ] Собеседник получает сообщение без перезагрузки страницы (< 500ms)
- [ ] При разрыве соединения — буфер сообщений + reconnect с backoff (1s→2s→4s→30s max)
- [ ] После переподключения — синхронизация пропущенных сообщений
- [ ] Сообщение не теряется при смене экрана

### US-12 — История сообщений

- [ ] Последние 50 сообщений загружаются при открытии чата
- [ ] Скролл вверх — подгружает следующие 50 (cursor-based pagination)
- [ ] История сохраняется в PostgreSQL
- [ ] Новые сообщения добавляются снизу, автоскролл если пользователь был внизу

### US-22 — Speaking indicator

- [ ] Говорящий участник имеет зелёный анимированный ободок вокруг аватара
- [ ] Ободок исчезает в течение 300ms после окончания речи
- [ ] Одновременно может говорить несколько участников (всем показывается ободок)

### US-25 — Persistent call bar

- [ ] При нахождении в голосовой комнате внизу экрана постоянно видна мини-панель
- [ ] Панель показывает: название комнаты, кнопку mute, кнопку выхода
- [ ] Панель не исчезает при переходе в чаты, настройки и другие разделы

## 5. Technical Architecture

### Stack

| Слой | Технология | Статус |
|---|---|---|
| Frontend | Flutter 3.x (Dart) | В разработке |
| State management | Provider → Riverpod (Фаза 2) | Provider активен |
| Backend | Go 1.22 + Gin | В разработке |
| ORM | GORM | Активен |
| База данных | PostgreSQL | Активна |
| Реал-тайм | WebSocket (Gorilla) + Hub pattern | Не начато |
| Голос | WebRTC + LiveKit SFU | Не начато |
| Медиа | MinIO (S3-совместимый) | Не начато |
| Уведомления | Firebase Cloud Messaging | Не начато |

### Backend — структура эндпоинтов (целевая)

```
POST   /auth/register
POST   /auth/login

GET    /user/search?q=
GET    /user/:id

GET    /friendship/pending          ← сделано
GET    /friendship/friends
POST   /friendship/
PATCH  /friendship/:user_id/status  ← нужно

GET    /chat/
POST   /chat/
GET    /chat/:id/messages?before=<cursor>&limit=50
POST   /chat/:id/messages

POST   /voice-room/
GET    /voice-room/
POST   /voice-room/:id/join
POST   /voice-room/:id/leave

GET    /ws?token=...                ← WebSocket upgrade
```

### WebSocket — типы событий

```json
{ "type": "message",       "payload": { "chat_id", "content", "sender_id" } }
{ "type": "typing",        "payload": { "chat_id", "user_id", "is_typing" } }
{ "type": "read",          "payload": { "chat_id", "message_id", "user_id" } }
{ "type": "presence",      "payload": { "user_id", "status": "online|offline" } }
{ "type": "friend_request","payload": { "from_user_id", "username" } }
{ "type": "room_update",   "payload": { "room_id", "user_id", "action": "join|leave" } }
```

### Database Schema (целевая)

```sql
users         (id, username, password_hash, created_at, deleted_at)
friendships   (user_id, friend_id, status, created_at)
chats         (id, created_at)
chat_members  (chat_id, user_id)
messages      (id, chat_id, sender_id, content, type, reply_to_id, created_at, edited_at, deleted_at)
reactions     (message_id, user_id, emoji, created_at)
read_status   (message_id, user_id, read_at)
voice_rooms   (id, name, created_by, is_active, created_at)
room_members  (room_id, user_id, joined_at)
```

## 6. Roadmap

### Фаза 1 — Базовый мессенджер (приоритет: сейчас)

**Цель:** два человека могут найти друг друга, подружиться и переписываться в реал-тайме.

**Критерий завершения:** US-01–US-06, US-10–US-14 выполнены и работают на десктопе.

```
Sprint 1 (1 неделя)
├── [US-05] PATCH /friendship/:user_id/status — принять/отклонить
├── [US-06] GET /friendship/friends — список друзей
└── [US-10] POST /chat/ — создать чат с другом (после принятия заявки)

Sprint 2 (1 неделя)
├── WebSocket Hub (Go) + эндпоинт GET /ws
├── WebSocket сервис (Flutter) с reconnect backoff
└── [US-07] WS-событие friend_request

Sprint 3 (1 неделя)
├── [US-11] Отправка/получение сообщений через WS
├── [US-12] История сообщений с пагинацией
├── [US-13] Typing indicator
└── [US-14] Статус прочтения (галочки)
```

### Фаза 2 — Богатый опыт (после Фазы 1)

```
Sprint 4-5 (2 недели)
├── [US-16] Реакции на сообщения
├── [US-15] Ответы/цитаты (swipe-to-reply)
├── [US-17] Отправка изображений
└── Статусы присутствия (online/offline)
```

### Фаза 3 — Голосовые комнаты (ключевая фича)

```
Sprint 6-7 (2 недели) — инфраструктура
├── LiveKit SFU + coturn TURN-сервер
├── [US-20] Создание комнаты
├── [US-21] Вход в комнату
└── [US-23/24] Mute + выход

Sprint 8-9 (2 недели) — UI
├── [US-22] Speaking indicator (зелёный ободок)
├── [US-25] Persistent mini-bar
├── [US-26] Индикатор качества соединения
└── [US-27] Push-to-talk / VAD
```

### Фаза 4 — Полировка

```
Sprint 10-11 (2 недели)
├── Firebase push-уведомления
├── JWT refresh tokens
├── Оффлайн-кэш (drift/sqflite)
└── Rate limiting + валидация входных данных
```

## 7. Out of Scope (v1.0)

- Публичные серверы / каналы
- Боты и интеграции
- Групповые текстовые чаты (только DM в Фазе 1)
- End-to-end шифрование (рассмотреть в Фазе 4+)
- Мобильные push при закрытом приложении (Фаза 4)
- Аватары пользователей (кастомные изображения)
- Веб-версия (только Flutter desktop + mobile)

## 8. Risks

| Риск | Вероятность | Влияние | Митигация |
|---|---|---|---|
| LiveKit сложно интегрировать | Средняя | Высокое | Начать с простого P2P WebRTC для 2 человек, SFU добавить позже |
| WebSocket reconnect ломает состояние | Высокая | Среднее | Тестировать сценарии разрыва с первого дня |
| TURN-сервер нужен сразу | Высокая | Высокое | Развернуть coturn параллельно с LiveKit |
| Provider → Riverpod рефакторинг | Средняя | Среднее | Делать постепенно, фича за фичей |
